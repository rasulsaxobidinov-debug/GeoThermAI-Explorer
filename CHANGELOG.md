## Versioning Strategy

This project follows Semantic Versioning.

Version format:

MAJOR.MINOR.PATCH

* **MAJOR** — incompatible architecture or API changes.
* **MINOR** — new features and functionality.
* **PATCH** — bug fixes, documentation updates and minor improvements.

Example:

* 0.1.0 — Initial repository
* 0.2.0 — Landing Page
* 0.3.0 — Dashboard
* 0.4.0 — Interactive GIS
* 0.5.0 — AI Analysis Module
* 0.6.0 — Report Generator
* 0.7.0 — Authentication System
* 0.8.0 — Organization Workspace
* 0.9.0 — MVP Release Candidate
* 1.0.0 — Official Competition MVP
