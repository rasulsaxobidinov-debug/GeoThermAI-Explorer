# Code of Conduct

## Our Commitment

GeoThermAI Explorer is committed to fostering a welcoming, professional, respectful, and collaborative environment for everyone.

We believe that scientific progress and software innovation are achieved through open collaboration, mutual respect, and constructive communication.

Participation in this project means contributing to a community that values professionalism, integrity, diversity of ideas, and responsible use of technology.

---

# Our Values

We encourage every contributor to:

* Be respectful and professional.
* Share knowledge openly.
* Support other contributors.
* Welcome constructive feedback.
* Focus on scientific accuracy.
* Promote reproducible research.
* Respect different perspectives and experiences.
* Help create a positive and inclusive community.

---

# Expected Behavior

Examples of behavior that contribute to a positive environment include:

* Using respectful language.
* Providing constructive technical feedback.
* Accepting different opinions.
* Helping new contributors.
* Improving documentation.
* Reporting issues responsibly.
* Giving appropriate credit to contributors.
* Maintaining high engineering standards.

---

# Unacceptable Behavior

The following behavior is not acceptable:

* Harassment of any kind.
* Personal attacks or insults.
* Discrimination.
* Offensive or abusive language.
* Publishing confidential information.
* Deliberate disruption of discussions.
* Plagiarism or misrepresentation of work.
* Sharing malicious code or security vulnerabilities publicly.

---

# Scientific Integrity

Because GeoThermAI Explorer supports scientific and engineering work, contributors are expected to:

* Present results honestly.
* Clearly distinguish measured data from predictions.
* Document assumptions.
* Avoid misleading visualizations.
* Cite external datasets where required.
* Respect intellectual property rights.

---

# AI Ethics

Contributors should ensure that Artificial Intelligence components are developed responsibly.

We encourage:

* Explainable AI
* Transparent methodologies
* Responsible data usage
* Reproducible workflows
* Human oversight for important decisions

GeoThermAI Explorer is intended to support decision-making, not replace expert judgment.

---

# Communication Guidelines

Please:

* Stay on topic.
* Be constructive.
* Explain technical decisions clearly.
* Keep discussions professional.
* Welcome questions from new contributors.

---

# Reporting Issues

If you experience unacceptable behavior or observe a violation of this Code of Conduct, please report it privately to the project maintainers.

Reports will be reviewed fairly and handled confidentially whenever possible.

---

# Enforcement

Project maintainers are responsible for interpreting and enforcing this Code of Conduct.

They may take appropriate actions, including:

* Private warning
* Temporary restriction
* Removal of inappropriate content
* Suspension of repository access
* Permanent exclusion from project collaboration

depending on the severity and frequency of the violation.

---

# Scope

This Code of Conduct applies to:

* GitHub Issues
* Pull Requests
* Discussions
* Project documentation
* Source code
* Community interactions related to GeoThermAI Explorer
